# v0.1 联调与验收

本清单区分可自动验证的软件逻辑与仍需真实硬件验证的行为。演示点击或模拟对方同意不算真实用户测试或无线测试证据。

## 测试前

确认供电与电池路径安全、EP 接地、晶振/RF/天线布局、芯片真实型号与 SWD 连通。按 `硬件/原理图审查_2026-10-09.md` 关闭仍未修复的问题。初次使用限流电源，不以固件编译成功推断硬件安全。

准备两台 nRF52832-QFAA，SWD 烧录器，两台支持的手机，以及 USB 电流仪／万用表。首版不依赖振动器，不读取充电器 CHRG 脚。

## 功能验证

| 项目 | 操作 | 应有结果 |
|---|---|---|
| 首次启动 | 刷入固件后不配手机 | 不广播匹配摘要；前 60 秒可进入配置连接 |
| 绑定与权限 | 用 App 或 Chrome 连接并接受系统绑定 | 加密后可订阅 TX、读取 status；被拒绝时给出失败信息 |
| 配置确认 | 修改标签并同步 | 只有固件 Flash 成功后 App 显示版本已确认 |
| 离线同频 | 两台同阶段、同标签，分别配置并断开手机 | 持续出现约 2 秒后，各自绿灯短闪并写记录 |
| 双向门槛 | A 门槛1，B门槛2，只有1个共同标签 | 双方都不提醒 |
| 不同标签／阶段 | 修改一台标签或切换阶段，完成同步 | 不提醒 |
| 校友规则 | 切校友，分别测异校、同校、任一方要求同校 | 按双向规则判断 |
| 去重 | 同一临时代号持续靠近 | 10 分钟内只记录一次；轮换代号后的行为另记 |
| 过期 | 用测试工具把意向设为短时有效 | 到期后停止摘要广播与扫描 |
| 暂停 | App 关闭发现但先不连接，再连接同步 | 未同步前硬件状态不变；确认后才暂停 |
| 掉电 | 产生记录后断电重启 | 配置／记录保留；校时前不恢复匹配 |
| 日志分页 | 产生超过8条记录，重复点击同步 | 每批最多8条；重复下载不覆盖本机隐藏／屏蔽设置 |
| 环形容量 | 写满并超过64条 | 覆盖最老记录，无越界；返回有效游标 |
| 连接中断 | 写配置或读分页时断蓝牙 | 不假报成功；重连从保留记录重试 |
| Flash 失败 | 在测试构建中注入写失败 | 不确认新配置；不提示已持久化相遇；红灯故障短闪 |
| 绑定窗口 | 重启超过60秒，用未绑定手机连接 | 连接被过滤；已绑定手机仍可同步 |
| 手机系统 | 桌面 Chrome/Edge、Android 原生、iPhone 原生 | 分别记录权限、绑定、分片、重连行为 |

## 无线与功耗

记录发现延迟、短暂擦肩漏检率、遮挡和外壳影响；RSSI 不转换为米。测正常扫描平均电流、提醒电流、连接电流、关发现电流和低电压行为。需要真实 168 小时或可信电流积分才能评价一周续航。

ADC 按 1MΩ/1MΩ 和 40µs 采样时间实现。需测对万用表的误差，并检查采样输入建立时间；百分比仅为线性估计。
