## 构建环境与产物

- Windows；Node.js 24.19.0；Capacitor 8.5.3；BLE插件8.3.0。
- 固件使用Zephyr 2.7.1、GNU Arm Embedded 8.2.1、CMake 3.21.3、Ninja 1.9.0。
- `platformio run` 的完整SDK安装流程曾因GitHub连接失败中断。已通过的入口是 `firmware/tools/build.py`，它使用相同SDK并只加载三个必要模块，没有修改第三方SDK的manifest。
- Python 3.13缺少旧SDK所需的distutils，已在项目独立虚拟环境加入固定版本setuptools提供兼容。构建日志仍有SDK弃用提示与GDB索引缓存提示，均不阻止编译。
- 交付镜像：`outputs/radar-v0.1/UniversityRadar_nRF52832_v0.1.0.hex`。同目录保留BIN、ELF、构建日志及包含SHA-256和源码散列的 `firmware-manifest.json`。
